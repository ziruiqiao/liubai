# 留白 · 使用与开发说明

当前版本 0.6.11。最近变化见[更新日志](../CHANGELOG.md)。

一个只听声音的原生 macOS 专注空间：播放哔哩哔哩公开视频的独立音频，同时提供番茄钟、每日统计和本地手记。没有视频视图、封面图、推荐流或弹幕。

界面每页仅保留 1–2 句理念文案：侧边栏一句，专注时钟内按阶段再显示一句。能由控件或数据说明用途的卡片不再重复加标题；目标使用输入提示，今日统计直接显示指标。其他位置使用简短的功能名称、状态与必要操作说明。

## 打开应用

发布构建产物位于 `dist/release/留白.app`，双击打开即可。可自行拖入「应用程序」。支持 macOS 14 或更新版本，发布构建同时包含 Apple Silicon 和 Intel 架构。发布构建后，旧入口 `dist/留白.app` 也会指向这个新版；构建时旧 App 包暂存到 `dist/release/previous/`，旧进程正常退出后可以清理。更新后先按 `⌘Q` 退出正在运行的旧进程，再打开 App。

应用采用本地 ad-hoc 签名，尚未使用 Apple Developer ID 签名或公证，也没有提交 App Store。

1. 首次打开已放入你提供的 [纯音乐播放列表](https://www.bilibili.com/video/BV1m2pTzCEXc/)。在「我的音乐」点击「添加音乐」，还可以添加其他视频链接、BV / av 号或 b23.tv 分享链接。
2. 在「我的音乐 → 导入合集」粘贴 UP 主合集或系列链接，预览全部条目后勾选或一键加入。在「本地合集」单独浏览、播放该合集。
3. 在「我的音乐 → B 站收藏夹」扫码登录，浏览自己创建的收藏夹并批量加入音乐。登录功能仅用于收藏夹读取。
4. 点击音乐的播放按钮，单独收听音乐，也可以同时开始番茄钟。在「偏好设置」调整专注、短休息、长休息时长和循环规则。
5. 在「时光统计」查看近 7 / 30 天的数据，在「每日手记」按日期记录心情和文字。

关闭主窗口后播放与计时继续运行，可通过菜单栏打开主窗口。菜单栏“打开留白”会优先唤出已有窗口（包括最小化的窗口），只有关闭主窗口后才重新创建。菜单栏弹窗可直接上一首、播放 / 暂停、下一首，切歌沿用当前播放列表；也可直接切换主题。弹窗使用完整动态天空，日月直径缩为 186 点，占弹窗面积约四分之一；计时数字使用小卡片。退出 App 或 Mac 休眠会暂停计时，重新打开后手动继续。

专注和休息切换时，**音乐默认持续播放**。阶段完成的双音提示通过独立音频播放器与音乐混音，不使用系统警告声通道。需要休息时静音，可以主动开启「休息时自动暂停音乐」。0.1 的默认自动暂停设置在升级时会一次性关闭，之后保留用户主动设置。

## 收藏夹与合集

支持现行 `space.bilibili.com/<UID>/lists/<ID>?type=season` 合集链接、`type=series` 系列链接、旧版合集 / 系列详情链接、多分 P 视频和 b23.tv 分享链接。视频有多个分 P 时，直接粘贴该视频链接会导入全部分 P；单 P 视频若属于 UP 主合集，会读取所在合集。

例如，你提供的[纯音乐与白噪音合集](https://space.bilibili.com/1252412810/lists/8996743?type=season)已验证跨页读取 147 项。UP 主合集按每个视频的默认第一 P 加入；需要某个视频的全部分 P，可以单独导入该视频链接。

导入先展示列表，可取消不想加入的条目。所有分页会完整读取，按视频与分 P 去重；再次导入同一合集会补充新条目。收藏夹内失效或不支持的内容会显示跳过数量。每个导入来源保留为本地合集，支持独立循环播放。

三个入口按来源分开：“我的音乐”仅显示通过“添加音乐”单独加入的条目；“本地合集”仅显示明确导入的合集；“B 站收藏夹”读取账号里的收藏夹。收藏夹内容可以明确保存为本地合集，不会自动加入“我的音乐”。同一首歌可以同时属于多个来源，移除或排序只影响当前来源。删除本地合集时，同时移除仅属于该合集的播放信息，保留其他合集或单独添加的同一首音乐，B 站上的内容不变。

升级时补齐旧数据的来源归属，并清理旧版删除合集后遗留、没有来源的批量导入条目；旧版单独添加的音乐与仍保留的合集会留下，迁移前的数据保留为备份。

**不会下载音频文件。** 批量导入只保存 BV 号、标题、时长、分 P 和合集归属。用你这份 147 项合集实测，连同初始音乐和少量配置，JSON 约 60 KB，另保留上一份备份。真正点播放时才解析当前条目的音频流，播放地址不长期保存。

对于带 `sidx` 索引的 DASH 音频，只读取开头的索引和当下需要的 AAC 片段，并在内存中提供给原生 HLS 播放器。内部 HTTP 入口仅绑定 `127.0.0.1` 随机端口与随机路径，不开放到局域网，不接收账号凭据，也不写音频文件。每个片段读取有大小上限，拒绝忽略 Range 的 CDN；拖动时直接请求目标片段，避免 AVFoundation 在长音频开始前扫描接近整个文件。非分片 MP4 保留原有范围读取兼容路径。首个 CDN 加载过慢时自动尝试备用地址。

参考 Apple 关于[自定义资源加载与缓冲预测](https://developer.apple.com/documentation/avfoundation/avplayer/automaticallywaitstominimizestalling)的说明，以及 [HLS 分片 MP4](https://developer.apple.com/documentation/http-live-streaming/hls-authoring-specification-for-apple-devices)规范。

登录使用 B 站手机 App 扫码。B 站发放的是普通网页会话，不提供“只读收藏夹”的细分服务端授权；留白在代码中将已登录请求限制为这两个 **GET** 接口：

```text
/x/v3/fav/folder/created/list-all
/x/v3/fav/resource/list
```

仅保存会话标识与 UID，不保存 CSRF 或刷新令牌。收藏夹客户端与播放器使用隔离的网络会话；扫码请求不携带保存的凭据，已登录凭据仅附加到上述收藏夹请求，也不跟随重定向转发。勾选「记住登录」时凭据保存在 macOS 钥匙串，取消勾选时仅在本次会话内使用。退出登录清除本地连接与保存的凭据，手动导入的音乐仍保留。当前读取的是用户自己创建的收藏夹，包括有权访问的私密收藏夹。

快捷键：`⌘L` 添加音乐；`⌘Return` 开始 / 暂停番茄钟；`⌥⌘Space` 播放 / 暂停；`⌘1…4` 切换页面；`⌘,` 打开偏好设置。

## 专注页布局

左上角按钮可折叠或展开导航栏，也可按 `⌃⌘S`，应用会记住选择。专注页播放栏使用圆角半透明悬浮样式，与窗口边缘留出空隙，天空延伸到其四周和下方；其他页面保留常规播放栏。

透明时钟圆盘固定直径 200 点，以整个窗口（含导航、标题栏和播放区）的中心定位，不随导航展开折叠而偏移，也不随窗口放大而变大。右侧宽度固定为 268 点，上方按原顺序放统计、目标和音乐卡片；阶段切换、开始暂停、重置、设置和轮数集中在右下角。“预览天空”和本地时间分别靠透明行的左右两端。多出的空间留给天空。音乐卡片显示当前播放内容，未播放时显示“我的音乐”中的第一项；完整列表仍在音乐页。最小 1080 × 760 窗口也能完整显示常用卡片，无需整页滚动。

## 主题配色

点击 macOS 菜单栏里的留白图标，在弹窗上方的「主题」菜单中选择莓红、橘光、麦黄、新绿、青苔、湖青、蔚蓝、晴蓝、鸢尾或樱粉，共十套主题。切换带有短暂的颜色过渡，并记住选择；系统开启“减少动态效果”时直接切换。默认晴蓝：靛蓝强调色、冷白底、深蓝灰文字。系统应用图标固定为白底黑色叶子，Dock 和 Finder 均不随主题换色；页面内的品牌图标跟随主题平滑变色。

自定义配色只改 [Resources/Theme.json](../Resources/Theme.json)，修改后重新构建即可。`colors` 是默认配色，`themes` 中各主题只需填写不同的颜色，`defaultTheme` 指定默认主题。这里包含导航栏、播放器、卡片文字和图标、计时控制区、菜单栏控件的颜色，以及常用卡片透明度；`iconTop`、`iconBottom`、`iconGlyph`、`iconRing`、`iconShadow` 控制固定的系统 App 图标，构建时会按同一份配置生成；`logoTop`、`logoBottom`、`logoGlyph` 单独控制页面内的主题图标。颜色可写六位十六进制，菜单栏的 `systemLabel` 表示跟随 macOS 的明暗文字色。

[Theme.swift](../Sources/LiuBai/Theme.swift) 负责读取配置并提供界面颜色。天空的原有配色独立保存在 [SkyPalette.swift](../Sources/LiuBai/SkyPalette.swift)，换界面主题不会改变日月、云星、天气或天空渐变。

## 系统天气背景

天气默认跟随 Mac 的 Core Location 系统定位，移动到其他城市时自动更新；不读取 Apple“天气”App 的私有配置，也不把时区当作实际城市。首次使用需在 macOS 提示中允许“留白”使用定位。如果系统定位关闭或未授权，右上角天气入口可打开定位设置，计时与音乐仍可正常使用。

位置立即粗化到 0.1 度，再用于城市名称和天气查询；不保存坐标或位置历史。当前天气来自 [Open-Meteo](https://open-meteo.com/en/docs)，按约 15 分钟刷新，属于天气模型的当前估计。只保存“天气背景”开关；天气缓存停留在内存，断网后最多短暂使用新鲜数据，过期后恢复无天气效果的天空。

普通雨雪使用稀疏粒子，多云增加云层；暴雨和暴雪使用更密、更快的雨雪粒子，风以加速的白云和细风线表现。保留原有明亮配色，不加雷声、闪电或阴暗滤镜。大雨等真实天气仍按数据源名称显示，并依据天气编码选择相应强度的背景。支持系统“减少动态效果”，窗口隐藏时停绘。点击“预览天空”可单独查看晴、多云、雨、暴雨、雪、暴雪、风，不改变真实天气、定位或计时。天气关闭时右上角入口仍保留，可直接重新开启。

天气来源及许可见 [Notices/Weather.md](../Notices/Weather.md)。本版使用无需 API 密钥的非商业天气服务，不携带 B 站登录凭据。

## 随本地时间变化的天空

整个“专注空间”页面绘制动态天空，并延伸到透明标题栏与窗口顶部圆角，保留 macOS 原生窗口按钮；使用电脑自己的时区。当前以本地 **06:00–18:00** 为日间，其余时间为夜间，清晨和黄昏的天空颜色渐变过渡；日月轨迹本身不请求定位，也不计算所在地的天文日出日落。

卡片右上角的「预览天空」可打开交互预览，默认只显示完整天空；需要观察遮挡效果时，可开启「计时卡片」，在角落显示缩小的只读卡片。拖动 0–24 点的时间滑块，或直接选清晨、上午、正午、黄昏、夜晚、午夜。可以暂停装饰动画或用 8 倍速度观察云和星群运动。预览不会更改电脑时间，也不会操作正在运行的番茄钟。

- 太阳与月牙的直径固定为 264 / 310 个逻辑点，不随窗口缩放；轨道跨越整个专注空间，在页面边缘自然裁切，也会被半透明卡片柔和遮挡。
- 云按固定尺寸在不同高度横向飘动，各层速度不同，明显快于按真实小时移动的太阳。空间增大时增加云和星星的数量，不拉大图形。
- 夜间星群围绕固定星极做圆周运动，约七分钟一圈，没有闪烁效果。
- 天空随真实时间运行，暂停或重置番茄钟不会重置天空。天空仅显示在专注页面，其他页面保留简洁背景。卡片使用约 74–82% 不透明度的浅色底，保护文字的可读性。

背景由原生矢量图形实时绘制，不加载视频或图片文件，不增加音乐缓存。装饰动画限制为 15 fps；窗口最小化或完全被遮挡时停绘。跟随系统「减少动态效果」时，云与星群保持静止，天色与天体位置仍按本地时间更新。

天空采用分时段的三层渐变：日间以亮天蓝与白云为主，日出用天蓝、粉霞、杏金，黄昏用蓝紫、桃粉、亮橙。时段之间按色相、饱和度和亮度插值，避免蓝色与橙色在整个背景中混成灰褐色。参考 [Wilms 与 Oberfeld 的颜色与情绪研究](https://link.springer.com/article/10.1007/s00426-017-0880-8)及[真实图像的色彩与饱和度研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC10867063/)；具体色号是结合用户反馈作出的设计选择。

终端中可用 `open output/focus-space/focus-09.0-1200.png` 查看完整专注空间，夜间图为 `output/focus-space/focus-21.0-1200.png`；文件名含 `1600` 的图片展示更大的窗口。旧版天空配色对比仍在 `output/sky-colors/before-after.png`。

## 计时与心情

短休息后的自动专注和长休息后的自动新循环分别设置；新循环默认等待手动开始。因休息自动暂停的音乐，仅在下一段专注真正开始计时时恢复；等待手动开始或只切换阶段时不恢复。阶段提示音使用双音提示，与音乐混音播放，偏好设置中可调音量并试听。每日手记的「添加心情」支持保存 1–12 字的自定义选项，保存后会选中；选项随本地数据保留，多于一行时可横向滚动。

## 统计口径

专注空间的目标会保存在对应的专注时间块中；在“时光统计 → 专注时间块”按日期查看目标、起止时间、实际专注时长和完成状态。每轮一块，暂停与继续保留为同一块，暂停和离线时间不计入时长；重置或切换阶段会保留已专注的部分。跨午夜的同一轮按当地日期显示对应部分。中途补写目标会更新当前尚未结束的一轮，已结束时间块的目标不受后续编辑影响。时间块随本地数据保存和导出，升级前只有每日汇总的记录不会被补造为时间块。

- **使用时长**：主窗口在前台、音乐正在播放、番茄钟正在运行时的时间并集，重叠时只计一次。
- **收听时长**：AVPlayer 实际播放的时间，不包含网络解析、缓冲和暂停。
- **专注时长**：番茄钟「专注」阶段实际运行的时间；休息不计入，中途暂停或重置前的时间会保留。
- **番茄轮数**：只有专注阶段自然完成才加一。切换阶段、重置或跳过不会增加轮数。
- **是否使用番茄钟**：当天启动过专注计时即可标记使用，不要求完成一轮。

按本地日历在午夜拆分时长，轮数归属实际完成的那一天。休眠期间不累计时间；异常长时间挂起的回调也会限制补记，避免虚增时长。

## 数据与备份

应用没有自建后端或云同步。列表、合集、统计与手记的数据目录：

```text
~/Library/Application Support/LiuBai/
  liubai.json
  liubai.backup.json
```

日记和设置在停止输入约半秒后自动保存，统计每 15 秒保存，退出时再次保存。手记正文、标题和专注目标保留输入法组合中的拼音或候选文字，仅在确认后写入保存队列；保存和界面刷新不会重设未确认的输入或光标。采用原子写入，每次保存保留上一份有效文件。若文件损坏，会显示错误并保留原文件，不会以空数据覆盖。数据是本地明文，请按自己的需要管理系统磁盘与备份。

「偏好设置」可导出全部 JSON 数据；每篇手记可以单独导出 Markdown。登录凭据从不包含在这些 JSON 或手记导出中。恢复备份时先退出应用，保留现有文件，再将备份命名为 `liubai.json` 放回数据目录。

早期直接使用的调试 App 将数据保存在项目的 `.local-data/`。从本项目目录首次启动发布版时，如果发布目录还没有用户数据，会复制旧版数据以保留当前使用记录，原文件也会保留。已有发布版数据始终优先。独立预览使用 `.local-data/preview-*/`，不会自动迁入正式使用的数据目录。更新前请先退出旧版，保证最后的记录已保存。

## 开发与验证

使用 Swift、SwiftUI、AppKit、AVFoundation 和 Swift Charts。没有第三方运行时依赖，也不依赖 Electron。安装 macOS Command Line Tools 后即可编译，不要求完整 Xcode。

```bash
# 发布版：生成双架构 .app 和 zip
bash scripts/build.sh

# 将已有发布版打成带“应用程序”入口的 DMG、版本化 ZIP 和校验文件
bash scripts/package-release.sh

# 单架构调试版，独立开发数据目录
bash scripts/build.sh debug x86_64
# Apple Silicon 开发机使用 arm64

# 计时、跨天 / 夏令时、持久化和链接解析检查
bash scripts/check.sh

# 联网检查：解析一个公开视频，静音播放、拖动进度，并检查视频轨道数为 0
bash scripts/check.sh --network
# 验证指定视频
bash scripts/check.sh --network BV1m2pTzCEXc
# 验证合集所有分页、首项播放与轻提示音期间的连续播放
bash scripts/check.sh --collection 'https://space.bilibili.com/1252412810/lists/8996743?type=season' --play-first
# 仅验证二维码生成与待扫码状态，不登录账号
bash scripts/check.sh --qr
```

可以用 `LIUBAI_DATA_DIR=/some/path` 指定开发数据目录。打包时还可设置 `LIUBAI_OUTPUT_DIR` 和调试用的 `LIUBAI_BUNDLE_ID`，避免与正在使用的版本冲突。工程拆分为 `LiuBaiCore`（数据 / 计时 / 统计 / B 站接口）、`LiuBaiAudio`（纯音频资源加载 / 混音提示声）和 `LiuBai`（macOS 界面）。

## 当前边界

- 登录仅用于读取收藏夹；播放器仍使用公开接口，不将收藏夹会话用于播放、会员音质或需权限的内容。收藏夹与合集是手动导入的本地快照，没有后台自动同步。
- B 站公开接口和 CDN 会变化，也可能返回风控错误。失败时会提示重试，不尝试绕过登录、付费或内容访问权限。接口和音频均使用直连，尚无应用内代理配置。
- 不缓存音频文件供离线收听，音频只在播放时经内存分段传递；临时播放地址在播放前重新解析。
- 尚未实现 iOS 客户端和设备间同步。核心数据、计时和接口层已与 macOS 界面分开，便于后续复用。iOS 分发与是否上架需在确定账户、内容授权和发行方式后另行评估。
